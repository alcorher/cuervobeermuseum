# Cuervo Beer Museum

Cuervo Beer Museum es una web dedicada a la historia, la cultura y la elaboración de la cerveza. Presenta un museo cervecero ficticio con información sobre sus exposiciones, talleres y propuestas para los visitantes.

Este proyecto ha sido realizado como trabajo final de la asignatura **LMSYG**.

## Secciones

- **Descúbrenos:** información sobre el museo y su historia.
- **Exhibiciones:** recorrido por la historia de la cerveza y su elaboración.
- **Talleres:** actividades de cerveza artesanal, catas y tiraje.
- **Contáctanos:** información para visitar el museo.

## Tecnologías

- HTML5
- CSS3
- JavaScript

## Ejecutar el proyecto

No requiere dependencias. Clona el repositorio y abre `index.html` en un navegador. También puedes utilizar una extensión como **Live Server** para ejecutarlo desde un servidor local.
